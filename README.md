# Decoupled Authentication for UAV Handover and Edge Service Migration Without Clock Synchronization

This repository contains the experimental source code for the authentication scheme, including protocol implementation, formal security verification, network simulation, and cryptographic benchmarking.

## Repository Structure

| Directory     | Description                                      |
| ------------- | ------------------------------------------------ |
| `protocol/`   | Authentication protocol implementation and tests |
| `tamarin/`    | Tamarin formal security verification models      |
| `simulation/` | ns-3 / IoD-Sim network simulation code           |
| `benchmarks/` | Cryptographic benchmarking code                  |
| `configs/`    | Experimental configuration files                 |
| `scripts/`    | Experiment execution scripts                     |
| `docs/`       | Environment setup and usage instructions         |

## Usage

For environment setup, compilation, and execution instructions, please refer to `docs/ENVIRONMENT.md` and the README files in the corresponding experiment directories.
